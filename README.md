# Site para Paula

Atualmente o site mostra uma tela de aviso ("Uma nova atualização está por vir, aguarde") com um temporizador de 15 dias.

```
index.html              Tela de aviso
assets/css/style.css    Estilo
assets/js/contagem.js   Temporizador (altere `dataLancamento`) e corações de fundo
assets/img/icones/      Favicon
```

Para mudar a data final do temporizador, edite `dataLancamento` em `assets/js/contagem.js`.

A versão completa anterior está guardada em `Site_Para_Paula_versao_anterior.zip`.
